# Zerg 0.3.0 — release notes

The third release, and the one where the **grammar stops being a promise**. 0.2.0's sentence was _the
specification stops disagreeing with the compiler_. This one is narrower and harder: the specification was
right, and the forms it derived were not built. Seventeen of them are now.

It has a second subject that nobody planned and that took more of the release than the first:

- **the grammar is implemented** — the forms `GRAMMAR` derives are lowered, not refused
- **the gates were audited against themselves** — a green gate proves only what it checked, and a dozen of
  them were checking less than they claimed

The short version is [`CHANGELOG.md`](../../CHANGELOG.md) at the repository root. This is the long one.

## How to read this

**Which compiler.** `make` builds two. `zerg0` is a Go-hosted seed whose only job is building the compiler;
`zerg` is that compiler, written in Zerg, and the one a build puts in `bin/`. **Every claim below is about
`zerg`.**

**The standing contract is unchanged.** A form is either lowered correctly or refused **by name** at compile
time, with a code and a place. Nothing new is silent.

## The grammar is implemented

Seventeen forms that `GRAMMAR` derived and `zerg` refused now compile. The ones a reader meets first:

- **Generic `struct`, `impl` and `fn`.** A declaration is a template and an application is an ordinary type
  with that name — `Box[int]` is a name, not a new shape in the type tree. An `impl` may carry its own
  `[T]`, may name type arguments in its target, and a `derive` reaches a generic.
- **`Ref[T]`** — the counted cell, with `deref`, and a drop that runs per box rather than per address.
- **Associated functions** (`Type.f(…)`) and **associated values** (`SIZE := 4096`).
- **Destructuring in both directions**, **struct, list, tuple and or-patterns**, and `pattern as name`.
- **The array type `[T; N]`**, a `spec` member with a body, and a `mut &` parameter in a function type.
- **The command literal**, an f-string's `{x!r}` / `{x=}` / `{x:spec}` tails, `asm`, `ptr`, and a standalone
  `unsafe fn`.
- **`x is T`** folds where the name denotes a complete type, and `a.len()` on an array no longer eats the
  expression that produced the array.

Seven `E9xxx` codes retired and two narrowed. What is left is named, row by row with the code that refuses
it, in [`docs/surface/grammar.md`](../../docs/surface/grammar.md) § _What is specified and not built_ — and
`make chapter-codes` now fails if one of those rows outlives its form.

## The gates were audited against themselves

A dozen merges, and one sentence covers them: **a claim that is remembered is not a claim that is checked.**

- **`CORPUS_SKIP` held a case that builds.** Deleting a name from that list was the gate for a feature — in
  one direction. The recipe builds every skipped case now and fails on one that succeeds.
- **`LINT_SKIP` held a file that lints clean**, because the module it excluded could not be built when the
  line was written. There is no exclusion list any more.
- **`corpus`, `examples`, `desugar` and `oracle` compared what a program prints and not what it dies with.**
  All four compare stdout, stderr and the exit status now, byte for byte. A missing expectation is a claim
  that the case writes nothing, not an excuse to skip it.
- **`treesitter` read 347 of 769 sources** while its help line said every Zerg file in the tree. The list is
  derived now — 763 — with the two corpora that deliberately hold unreadable forms excluded by name.
- **Two refusals named a reason that had stopped being true**, and the grammar inventory listed seventeen
  built forms as unbuilt.
- **`reject-fuzz`, `layering`, `docs-repeat` and `refusal-cites`** gained floors or per-item guards where a
  single number could not see which part had gone.

## What a program gives back

`sanitize-conc` ran twenty concurrency cases under the sanitizers; the other 179 had never been under one.
The new **`sanitize-corpus`** gate runs them, and the first honest run found sixteen leaking in four classes.

Six are closed. A map releases the keys and values it owns; a map receiver materialised for an rvalue is
released; a map binding with a type annotation is registered like one without; an index into a map is a
BORROW rather than an rvalue, in the two arms that used to release one; and three formatting paths that were
handed a rendering they did not own now give it back.

The remaining ten are listed by name with the allocator beside each, and a deletion from that list is the
gate for the fix it records.

## Leftovers

Two finds from this release's own work ship unfixed, by the rule 0.2.0 set: a marker written by the work is
allowed to ship, so the criterion never rewards silence.

- [#123](https://github.com/cmj0121/zerg/issues/123) — `unsafe fn` as a `spec` requirement (`E9036`)
- [#124](https://github.com/cmj0121/zerg/issues/124) — `#[derive(From)]` on a built-in payload (`E9047`)

## The board

**58 gates**, up from 52. The new ones: `sanitize-corpus`, `refusal-cites`, `docs-repeat`, `generic-walks`,
`grammar-cited`, `build-deps-check`.
